# 3.5 顶点着色器

原书来源：书页 42—44（PDF 物理页 63—65）。

顶点着色器是图 3.2 所示功能流水线中的第一个阶段。虽然这是程序员能够直接控制的第一个阶段，但需要注意，在此之前已经进行了一些数据操作。在 DirectX 称为*输入装配器*（input assembler）的部分中 [175, 530, 1208]，可以将多个数据流交织在一起，形成送入流水线的顶点集合和图元集合。例如，一个物体可以用一个位置数组和一个颜色数组来表示。输入装配器通过创建带有位置和颜色的顶点，构造出这个物体的三角形（或者线、点）。另一个物体可以使用同一个位置数组（配合不同的模型变换矩阵）以及不同的颜色数组来表示。第 16.4.5 节将详细讨论数据表示。输入装配器还支持*实例化*（instancing）。它允许通过一次绘制调用将一个物体绘制多次，并让各个实例的某些数据有所不同。第 18.4.2 节将介绍实例化的使用。

三角形网格由一组顶点表示，每个顶点都对应模型表面上的一个特定位置。除了位置，每个顶点还可以关联其他可选属性，例如颜色或纹理坐标。表面法线也定义在网格顶点处，这种选择可能显得有些奇怪。从数学上说，每个三角形都有明确的表面法线，直接使用三角形的法线进行着色似乎更合理。然而，在渲染时，三角形网格通常用于表示其所近似的一个曲面，而顶点法线用于表示这个曲面的朝向，而非三角形网格本身的朝向。第 16.3.4 节将讨论计算顶点法线的方法。图 3.7 展示了两个表示曲面的三角形网格的侧视图，其中一个曲面平滑，另一个则带有一道尖锐的折痕。

![图 3.7 表示平滑曲面与折痕的三角形网格及顶点法线](https://raw.githubusercontent.com/ahuibo/Real-Time-Rendering-4th-CN/main/Real-Time_Rendering_4th_%E4%B8%AD%E6%96%87/assets/fig_3.5_3.7.png)

**图 3.7** 表示曲面（红色）的三角形网格侧视图（黑色，并绘有顶点法线）。左图使用平滑处理后的顶点法线来表示一个平滑曲面。右图将中间顶点复制了一份，并为其赋予两条法线，以表示一道折痕。

顶点着色器是处理三角形网格的第一个阶段。顶点着色器无法获取描述顶点如何构成三角形的数据。顾名思义，它只处理传入的顶点。顶点着色器提供了一种方式，可以修改、创建或忽略与各个三角形顶点关联的值，例如颜色、法线、纹理坐标和位置。通常，顶点着色器程序会将顶点从模型空间变换到齐次裁剪空间（第 4.7 节）。顶点着色器至少必须始终输出这个位置。

顶点着色器与前面描述的统一着色器大体相同。传入的每个顶点都由顶点着色器程序处理，随后程序输出若干值，这些值会在三角形或线段上进行插值。顶点着色器既不能创建顶点，也不能销毁顶点；处理一个顶点所产生的结果也不能传递给另一个顶点。由于各个顶点都被独立处理，因此可以使用 GPU 上任意数量的着色器处理器，并行处理传入的顶点流。

输入装配通常被描述为在顶点着色器执行之前发生的过程。这是物理模型往往不同于逻辑模型的一个例子。在实际物理实现中，为创建顶点而进行的数据读取可能发生在顶点着色器内部；驱动程序会悄然在每个着色器的开头添加适当的指令，而程序员看不到这些指令。

后续章节将解释几种顶点着色器效果，例如用于关节动画的顶点混合，以及轮廓渲染。顶点着色器的其他用途包括：

- 物体生成：只创建一次网格，再由顶点着色器使其变形。
- 使用蒙皮和变形技术，为角色的身体和面部制作动画。
- 程序化变形，例如旗帜、布料或水的运动 [802, 943]。
- 粒子创建：将退化的（没有面积的）网格送入流水线，再按需要使其具有面积。
- 镜头畸变、热浪扰动、水波纹、翻页卷曲以及其他效果：将整个帧缓冲区的内容作为纹理，贴在一个与屏幕对齐并进行程序化变形的网格上。
- 使用顶点纹理读取来应用地形高度场 [40, 1227]。

顶点着色器的输出可以通过几种不同的方式被使用。通常的路径是：接下来生成每个实例的图元（例如三角形）并对其进行光栅化，再将产生的各个像素片元送入像素着色器程序，继续处理。在某些 GPU 上，这些数据也可以被送入曲面细分阶段或几何着色器，或者存入内存。以下各节将讨论这些可选阶段。
