# 3.6 曲面细分阶段

原书来源：书页 44—46（PDF 物理页 65—67）。

曲面细分阶段使我们能够渲染曲面。GPU 的任务是接收每个曲面的描述，并将其转换为一组三角形来表示该曲面。这个阶段是一项可选的 GPU 功能，最早在 DirectX 11 中出现（并且是 DirectX 11 所要求的功能）。OpenGL 4.0 和 OpenGL ES 3.2 也支持它。

使用曲面细分阶段有几个优点。与直接提供相应的三角形相比，曲面的描述通常更加紧凑。除了节省内存之外，对于形状逐帧变化的动画角色或物体，这项功能还能避免 CPU 与 GPU 之间的总线成为瓶颈。通过针对给定视图生成适当数量的三角形，可以高效地渲染曲面。例如，如果一个球离相机很远，只需要少量三角形；而近距离观察时，使用数千个三角形来表示它，视觉效果可能最好。这种控制细节层次的能力，也使应用程序能够控制自身的性能，例如在性能较弱的 GPU 上使用质量较低的网格，以维持帧率。通常用平面表面表示的模型，可以转换为精细的三角形网格，然后按需要使其变形 [1493]；也可以对它们进行曲面细分，以降低执行高开销着色计算的频率 [225]。

曲面细分阶段始终由三个组成部分构成。采用 DirectX 的术语，它们分别是外壳着色器（hull shader）、曲面细分器（tessellator）和域着色器（domain shader）。在 OpenGL 中，外壳着色器称为曲面细分控制着色器（tessellation control shader），域着色器称为曲面细分求值着色器（tessellation evaluation shader）。这些名称虽然较为冗长，但描述性更强。在 OpenGL 中，固定功能的曲面细分器称为图元生成器（primitive generator）；正如后文所示，这确实就是它所做的工作。

如何描述曲线和曲面，以及如何对它们进行细分，将在第 17 章中详细讨论。这里简要介绍曲面细分各阶段的用途。首先，外壳着色器的输入是一种特殊的曲面片（patch）图元。它由若干控制点组成，这些控制点定义一个细分曲面、Bézier 曲面片，或其他类型的曲面元素。外壳着色器有两个作用。第一，告诉曲面细分器应该生成多少个三角形，以及采用何种配置。第二，对每个控制点进行处理。此外，外壳着色器还可以选择修改传入的曲面片描述，按需要添加或删除控制点。外壳着色器将其控制点集连同曲面细分控制数据一起输出给域着色器。见图 3.9。

**图 3.9** 曲面细分阶段。外壳着色器接收由控制点定义的曲面片，并将曲面细分因子（TF）及类型发送给固定功能的曲面细分器。外壳着色器根据需要对控制点集进行变换，再将其连同曲面细分因子和相关的曲面片常量一起发送给域着色器。曲面细分器创建顶点集及其重心坐标。随后，域着色器处理这些数据，生成三角形网格（图中显示控制点以供参考）。

曲面细分器是流水线中的一个固定功能阶段，仅与曲面细分着色器配合使用。它的任务是添加若干新顶点，供域着色器处理。外壳着色器向曲面细分器发送所需细分曲面类型的信息：三角形、四边形或等参线（isoline）。等参线是一组线条带，有时用于头发渲染 [1954]。外壳着色器发送的另一类重要数值是曲面细分因子（在 OpenGL 中称为曲面细分级别，tessellation levels）。它们分为两类：内部因子和外边缘因子。两个内部因子决定三角形或四边形内部的细分程度。外部因子决定每条外边缘的分割程度（第 17.6 节）。图 3.10 展示了增大曲面细分因子的示例。通过允许分别控制这些因子，无论内部如何细分，都可以使相邻曲面的边缘在细分上相互匹配。边缘匹配可以避免曲面片交接处出现裂缝或其他着色瑕疵。顶点会被赋予重心坐标（第 22.8 节），这些数值指定所需曲面上每个点的相对位置。

**图 3.10** 改变曲面细分因子的效果。犹他茶壶由 32 个曲面片组成。从左到右，内部和外部曲面细分因子分别为 1、2、4 和 8。（图像由 Rideout 和 Van Gelder 的演示程序生成 [1493]。）

外壳着色器始终输出一个曲面片，也就是一组控制点的位置。不过，它可以向曲面细分器发送一个小于或等于零的外部曲面细分级别（或非数值 NaN），以示意应丢弃该曲面片。否则，曲面细分器会生成一个网格，并将其发送给域着色器。每次调用域着色器时，都会使用外壳着色器提供的曲面控制点，计算每个顶点的输出值。域着色器的数据流模式与顶点着色器相似：对曲面细分器提供的每个输入顶点进行处理，并生成一个对应的输出顶点。所形成的三角形随后被传递到流水线的后续阶段。

虽然这套系统听起来很复杂，但它之所以采用这样的结构，是出于效率的考虑，而且每个着色器都可以相当简单。传入外壳着色器的曲面片通常只需很少的修改，甚至完全不需要修改。这个着色器还可以根据曲面片的估计距离或屏幕尺寸，动态计算曲面细分因子，例如用于地形渲染 [466]。另一种做法是，外壳着色器仅传递应用程序计算并提供的一组固定值，所有曲面片都使用这组值。曲面细分器执行一个复杂但固定功能的过程：生成顶点、赋予它们位置，并指定这些顶点组成哪些三角形或线段。为了提高计算效率，这一步数据扩增操作在着色器之外执行 [530]。域着色器取得为每个点生成的重心坐标，并将其用于曲面片的求值方程，以生成位置、法线、纹理坐标以及其他所需的顶点信息。图 3.11 给出了一个示例。
