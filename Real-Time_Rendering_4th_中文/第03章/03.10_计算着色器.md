# 3.10 计算着色器

来源：原书第 54—55 页（PDF 第 75—76 页）。

GPU 的用途不仅限于实现传统的图形流水线。在许多不同领域中，它还有大量非图形用途，例如计算股票期权的估计价值，以及训练用于深度学习的神经网络。以这种方式使用硬件称为 **GPU 计算**。CUDA 和 OpenCL 等平台把 GPU 当作大规模并行处理器来控制，并不真正需要图形专用功能，也不访问这些功能。这些框架通常使用带有扩展的 C 或 C++ 等语言，以及专为 GPU 编写的库。

DirectX 11 引入的**计算着色器**是 GPU 计算的一种形式，因为它是一种不固定在图形流水线某个位置的着色器。它通过图形 API 调用，因此与渲染过程紧密相关。它与顶点着色器、像素着色器以及其他着色器配合使用，并使用与流水线相同的统一着色器处理器资源池。它和其他着色器一样，具有某组输入数据，并且能够访问缓冲区（例如纹理）来进行输入和输出。在计算着色器中，线程束（warp）和线程更加显式。例如，每次调用都会获得一个可供自身访问的线程索引。此外，还有**线程组**这一概念；在 DirectX 11 中，一个线程组由 1 到 1024 个线程组成。这些线程组通过 x、y 和 z 坐标来指定，主要是为了方便在着色器代码中使用。每个线程组都有少量可在线程之间共享的内存。在 DirectX 11 中，这部分内存为 32 kB。计算着色器按线程组执行，从而保证组内的所有线程并发运行 [1971]。

计算着色器的一项重要优势是能够访问 GPU 上生成的数据。将数据从 GPU 发送到 CPU 会产生延迟，因此，如果能够让处理过程和结果都留在 GPU 上，就可以提高性能 [1403]。后处理，即以某种方式修改已经渲染好的图像，是计算着色器的一种常见用途。共享内存意味着，对图像像素进行采样所得到的中间结果，可以与相邻线程共享。例如，研究发现，使用计算着色器确定图像的亮度分布或平均亮度，其运行速度可达到使用像素着色器执行同一操作的两倍 [530]。

计算着色器还适用于粒子系统、面部动画等网格处理 [134]、剔除 [1883, 1884]、图像滤波 [1102, 1710]、提高深度精度 [991]、阴影 [865]、景深 [764]，以及其他任何能够利用一组 GPU 处理器来完成的任务。Wihlidal [1884] 讨论了计算着色器如何能够比曲面细分的外壳着色器更加高效。其他用途见图 3.16。

至此，我们对 GPU 如何实现渲染流水线的回顾就结束了。GPU 的功能可以通过多种方式使用和组合，以执行各种与渲染相关的处理。相关理论，以及为利用这些能力而调整的算法，是本书的核心主题。接下来，我们将把重点转向变换和着色。
