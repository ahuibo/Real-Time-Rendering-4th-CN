# 3.7 几何着色器

来源：原书第 47—49 页（PDF 物理页第 68—70 页）。

几何着色器能够把图元转换为其他图元，这是曲面细分阶段做不到的。例如，可以让每个三角形生成表示其边的线段，从而将三角形网格转换为线框视图。另一种做法是用面向观察者的四边形替换这些线段，由此渲染出边线更粗的线框 [1492]。几何着色器于 2006 年末随 DirectX 10 的发布加入硬件加速的图形流水线。它在流水线中位于曲面细分着色器之后，可以选择是否使用。虽然几何着色器是 Shader Model 4.0 的必备组成部分，但更早的着色器模型并不使用它。OpenGL 3.2 和 OpenGL ES 3.2 也支持这种着色器。

几何着色器的输入是单个对象及其关联顶点。该对象通常由三角形条带中的三角形、一条线段，或者仅仅一个点构成。也可以定义扩展图元，并由几何着色器处理。具体来说，可以额外传入三角形外部的三个顶点，也可以使用折线上的两个相邻顶点。见图 3.12。在 DirectX 11 和 Shader Model 5.0 中，可以传入更复杂的面片，最多含有 32 个控制点。话虽如此，对于面片生成而言，曲面细分阶段的效率更高 [175]。

![图 3.12：几何着色器的输入图元](https://raw.githubusercontent.com/ahuibo/Real-Time-Rendering-4th-CN/main/Real-Time_Rendering_4th_%E4%B8%AD%E6%96%87/assets/fig_3.7_3.12.png)

**图 3.12** 几何着色器程序的输入属于某一种单一类型：点、线段或三角形。最右边的两个图元还包含与线段对象和三角形对象相邻的顶点。也可以使用更复杂的面片类型。

几何着色器处理这个图元，并输出零个或多个顶点；这些顶点被视为点、折线或三角形条带。注意，几何着色器也可以完全不产生输出。这样，就可以通过编辑顶点、添加新图元以及移除其他图元，有选择地修改网格。

几何着色器的设计用途是修改传入的数据，或者生成数量有限的副本。例如，一种用途是生成数据经过变换后的六份副本，从而同时渲染立方体贴图的六个面；见第 10.4.3 节。它也可以高效地创建级联阴影贴图，以生成高质量的阴影。其他利用几何着色器的算法包括：根据点数据创建大小可变的粒子，沿轮廓挤出鳍片以渲染毛皮，以及为阴影算法寻找对象的边缘。更多示例见图 3.13。本书后续内容将讨论这些用途以及其他用途。

![图 3.13：几何着色器的应用示例](https://raw.githubusercontent.com/ahuibo/Real-Time-Rendering-4th-CN/main/Real-Time_Rendering_4th_%E4%B8%AD%E6%96%87/assets/fig_3.7_3.13.png)

**图 3.13** 几何着色器（GS）的一些用途。左图利用 GS 即时对元球（metaball）等值面进行曲面细分。中图利用 GS 和流输出对线段进行分形细分，并由 GS 生成公告板来显示闪电。右图利用顶点着色器、几何着色器和流输出进行布料模拟。（图片来自 NVIDIA SDK 10 [1300] 的示例，由 NVIDIA 公司提供。）

DirectX 11 增加了几何着色器使用实例化的能力，使几何着色器可以对任意给定图元运行指定次数 [530, 1971]。在 OpenGL 4.0 中，这是通过调用次数来指定的。几何着色器还可以输出最多四条*流*。其中一条流可以继续沿渲染流水线向下传递，接受进一步处理。所有这些流都可以选择发送到流输出渲染目标。

几何着色器保证按照图元输入的顺序输出其结果。这会影响性能，因为如果多个着色器核心并行运行，就必须保存结果并按序排列。这一点以及其他因素，使得几何着色器不适合在单次调用中复制或创建大量几何数据 [175, 530]。

发出绘制调用之后，流水线中只有三个地方能够在 GPU 上产生工作：光栅化、曲面细分阶段和几何着色器。其中，从所需资源和内存的角度来看，几何着色器的行为最难预测，因为它是完全可编程的。实际上，几何着色器通常很少被使用，因为它不能很好地发挥 GPU 的优势。在某些移动设备上，几何着色器通过软件实现，因此明确不建议在这些设备上使用它 [69]。

## 3.7.1 流输出

GPU 流水线的标准用法是将数据送入顶点着色器，然后对得到的三角形进行光栅化，再在像素着色器中处理它们。过去，数据总是一路通过流水线，无法访问中间结果。Shader Model 4.0 引入了*流输出*的概念。顶点经顶点着色器处理之后（也可以选择再由曲面细分着色器和几何着色器处理），除了可以继续送往光栅化阶段，还可以作为一条流，也就是一个有序数组输出。事实上，可以完全关闭光栅化，使流水线纯粹作为非图形用途的流处理器使用。以这种方式处理后的数据可以重新送入流水线，从而实现迭代处理。这类操作可用于模拟流水或其他粒子效果，相关内容将在第 13.8 节讨论。它也可以用于对模型进行蒙皮，随后让这些顶点可供重复使用（第 4.4 节）。

流输出只能以浮点数的形式返回数据，因此可能产生相当明显的内存开销。流输出作用于图元，而不直接作用于顶点。如果将网格送入流水线，每个三角形都会生成自己的一组三个输出顶点。原始网格中的所有顶点共享关系都会丢失。因此，更典型的用法是仅将顶点作为点集图元送入流水线。在 OpenGL 中，流输出阶段称为*变换反馈*，因为它的许多用途主要是变换顶点，然后将顶点返回，以便进一步处理。图元保证按照输入顺序发送到流输出目标，这意味着顶点顺序将得到保持 [530]。
