# 延伸阅读与资源

Giesen 的图形流水线导览 [530] 详细讨论了 GPU 的许多方面，解释各个组成部分为何以相应的方式工作。Fatahalian 和 Bryant 的课程 [462] 通过一系列详细的讲义幻灯片，讨论 GPU 并行性。Kirk 和 Hwa 的书 [903] 虽然着重介绍使用 CUDA 进行 GPU 计算，但其入门部分讨论了 GPU 的演进及设计思想。

系统学习着色器编程需要付出一些努力。《OpenGL Superbible》[1606] 和《OpenGL Programming Guide》[885] 等书都包含着色器编程内容。较早的《OpenGL Shading Language》[1512] 没有涉及几何着色器、曲面细分着色器等较新的着色器阶段，但它专门着重讨论与着色器有关的算法。较新的书籍和推荐读物，请参见本书网站 [realtimerendering.com](https://realtimerendering.com/)。
